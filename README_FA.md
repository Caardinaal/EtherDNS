## 📌 درباره پروژه

**EtherDNS** یک ابزار جامع، سریع و سبک برای تغییر DNS و مدیریت شبکه در سه سیستم‌عامل **ویندوز**، **لینوکس (اوبونتو / دبیان)** و **اندروید** است. این برنامه به شما امکان می‌دهد تنها با یک کلیک بین **بیش از ۸۷ سرور DNS معتبر ایرانی و جهانی** جابه‌جا شوید، سرورهای سفارشی خود را اضافه و ذخیره کنید، سرعت واقعی پاسخ‌گویی دی‌ان‌اس‌ها را روی پورت **UDP/53** تست کنید، مشخصات آی‌پی و ASN خود را بررسی کنید و شبکه‌های وای‌فای ذخیره‌شده را مدیریت نمایید.

---

## ✨ ویژگی‌های کلیدی

* **بیش از ۸۷ سرور DNS عمومی، خصوصی و تحریم‌شکن:**
  * **دی‌ان‌اس‌های ایران (۳۰ سرور):** شکن، شکن پرو، الکترو، رادار گیم، 403.online، بگذر، Dynx.pro، وانیلا، هاست‌ایران، بشکن، شلتر، گیم‌رادار و تمامی اپراتورها و دیتاسنترهای کشور (مخابرات، آسیاتک، شاتل، پیشگامان، مبین‌نت، پارس‌آنلاین، صبانت، تک‌نت، زیتل، ایرانسل، همراه اول، رایتل، افرانت، رسپینا و های‌وب).
  * **دی‌ان‌اس‌های جهانی و خصوصی (۵۷ سرور):** کلودفلر، گوگل، Quad9، OpenDNS، NextDNS، Control D، AdGuard، Mullvad، RethinkDNS، LibreDNS، Verisign، Level3، Gcore و سرویس‌های ضدتبلیغات (AdBlock)، امنیتی و خانواده.
* **مدیریت DNS سفارشی (Custom DNS Manager):** امکان افزودن سرورهای دلخواه با نام مشخص، آی‌پی‌های اول و دوم و دسته‌بندی؛ این سرورها برای همیشه در حافظه برنامه ذخیره شده و در تست سرعت همگانی شرکت داده می‌شوند.
* **تست سرعت موازی و واقعی روی UDP/53:** اندازه گیری دقیق زمان پاسخ‌گویی سرورها (پینگ واقعی DNS) به صورت هم‌زمان با استفاده از سوکت‌های چندرشته‌ای.
* **مانیتور زنده پینگ (Live Latency Monitor):** نمایش نمودار و زمان پاسخ‌گویی سرور فعال به صورت لحظه‌ای.
* **بازرسی مشخصات شبکه و آی‌پی عمومی:** نمایش آی‌پی عمومی، کشور، شهر، شرکت ارائه‌دهنده (ISP)، سازمان، ASN، منطقه زمانی، مختصات جغرافیایی، آی‌پی محلی، گوی‌وی (Gateway) و آدرس MAC.
* **ابزارهای پیشرفته شبکه (دسکتاپ):** پاک‌سازی کش DNS (Flush)، تمدید IP شبکه (Renew)، ریست کامل آداپتورهای شبکه و بازیابی رمزهای عبور وای‌فای ذخیره‌شده.
* **رابط کاربری مدرن و واکنش‌گرا (Matte Dark UI):** طراحی تیره، زیبا و بدون حواس‌پرتی با کارت‌های متوازن و قابلیت تغییر ابعاد پنجره از هر ۸ جهت.

## 💻 پشتیبانی پلتفرم‌ها

| پلتفرم | تکنولوژی ساخت | نحوه اعمال DNS | قابلیت‌های ویژه |
| :--- | :--- | :--- | :--- |
| **ویندوز** | C# / .NET 9 (WPF) | دستورات `netsh` / WMI | ابزارهای کامل دسکتاپ، بازیابی رمز وای‌فای، نمودار زنده پینگ |
| **اوبونتو / دبیان** | Python 3 / PyQt6 & PyQt5 | ابزار `nmcli` + `resolvectl` + `pkexec` | پکیج استاندارد `.deb`، تغییر سایز پنجره، پشتیبانی از گرافیک با دسترسی `sudo` |
| **اندروید** | Native Android Java SDK | سرویس محلی `VpnService` (TUN UDP/53 Forwarder) | **بدون نیاز به روت**، تست سرعت ۲۴ رشته‌ای در ۱.۵ ثانیه، نوتیفیکیشن وضعیت در نوار بالا |

## 📦 راهنمای نصب و ساخت

### ۱. اوبونتو و دبیان لینوکس (`.deb`)

**روش الف — نصب از طریق فایل نصبی آماده:**
```bash
sudo apt install ./etherdns_2.2.0_all.deb
روش ب — ساخت و نصب خودکار از طریق اسکریپت:

Bash
chmod +x install-etherdns-ubuntu.sh
sudo ./install-etherdns-ubuntu.sh
اجرای برنامه: برنامه EtherDNS را از منوی برنامه‌های اوبونتو باز کنید یا در ترمینال دستور sudo etherdns را بزنید.

حذف کامل: etherdns --uninstall

۲. اندروید (.apk)
روش الف — نصب مستقیم فایل نصبی:
فایل EtherDNS-v2.3.0-Android.apk را از بخش Releases دانلود کرده و روی گوشی نصب کنید (اندروید ۶ به بالا).

روش ب — ساخت فایل APK در اوبونتو (بدون نیاز به Android Studio و Gradle):
می‌توانید در کمتر از ۵ ثانیه فایل نصبی را روی لینوکس کامپایل کنید:

Bash
chmod +x build-android-ubuntu.sh
sudo ./build-android-ubuntu.sh
فایل امضاشده EtherDNS-v2.3.0-Android.apk در پوشه جاری و دسکتاپ شما ساخته می‌شود.

۳. ویندوز (.exe)
روش الف — نصب از طریق فایل ستاپ:
فایل EtherDNS-Setup-2.2.0.exe را دانلود و اجرا کنید.

روش ب — ساخت از سورس‌کد در ویندوز:
نیازمند .NET 9 SDK و Inno Setup 6. در محیط PowerShell اجرا کنید:

PowerShell
powershell -ExecutionPolicy Bypass -File .\update-and-build.ps1
فایل ستاپ در مسیر dist\EtherDNS-Setup-2.2.0.exe ساخته خواهد شد.
